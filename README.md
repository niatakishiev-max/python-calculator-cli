# Python Calculator CLI

Консольный калькулятор на Python.

## Возможности

- Сложение
- Вычитание
- Умножение
- Деление
- Защита от деления на ноль
- Проверка неправильного ввода числа
- Проверка неизвестной операции
- Цикл работы до выхода через `q`

## Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

## Запуск

```bash
python calculator.py
```

## Тесты

Для запуска автотестов:

```bash
python -m pytest
```

## Используемые технологии

- Python
- pytest
- CLI
- Git / GitHub

## Что показывает проект

Проект демонстрирует базовые навыки Python и автотестирования:

- функции
- условия `if / elif`
- цикл `while`
- обработку ошибок `try / except`
- работу с пользовательским вводом
- unit-тесты
- параметризацию тестов через `pytest.mark.parametrize`
- подмену пользовательского ввода через `monkeypatch`
- проверку вывода через `capsys`
