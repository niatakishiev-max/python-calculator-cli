# Python Calculator CLI

Консольный калькулятор на Python.

## Возможности

- Сложение
- Вычитание
- Умножение
- Деление
- Защита от деления на ноль
- Проверка неправильного ввода числа
- Проверка неизвестной операции
- Цикл работы до выхода через `q`

## Запуск

```bash
python calculator.py
```

## Используемые технологии

- Python
- CLI
- Git / GitHub

## Что показывает проект

Проект демонстрирует базовые навыки Python:

- функции
- условия `if / elif`
- цикл `while`
- обработку ошибок `try / except`
- работу с пользовательским вводом
